# Karpathy Guidelines

1. **Think Before Coding**:
   - Understand requirements, edge cases, contracts, and system constraints before writing code.
   - Clarify ambiguities and map out state transitions first.

2. **Simplicity First**:
   - Write clear, idiomatic, and minimal code to solve the exact problem.
   - Avoid premature abstraction, unnecessary boilerplate, or speculative features.

3. **Surgical Changes**:
   - Make precise, targeted changes that fit existing architecture and patterns.
   - Preserve existing code conventions, documentation, and unaffected files.

4. **Goal-Driven Execution**:
   - Keep end-to-end functionality and definition of done in focus.
   - Verify every flow against test cases, error states, and UX criteria.
